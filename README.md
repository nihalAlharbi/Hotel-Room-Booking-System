# Hotel Room Booking System

A hotel room booking web application developed with **C#**, **ASP.NET Web Forms**, and **.NET Framework 4.8**.

## Features

- User registration and login
- Room browsing and management
- Add, edit, and view bookings
- Payment and notification pages
- Booking statistics and dashboard

## Technology

- C# and ASP.NET Web Forms
- .NET Framework 4.8
- Visual Studio

Screenshots of the **actual running application** will be added here once captured from the project. This repository currently contains the source code but no verified interface screenshots.

## Project structure

- `WebApplicationRooms.sln` — Visual Studio solution
- `WebApplicationRooms/` — application pages, code-behind, and models
- `WebApplicationRooms/App_Data/` — local data directory (private records excluded)

## How to run

1. Open `WebApplicationRooms.sln` in Visual Studio on Windows.
2. Ensure the .NET Framework 4.8 targeting pack and ASP.NET web development tools are installed.
3. Restore required NuGet packages if prompted.
4. Configure local test data as needed, then run the application.

**Note:** Personal user and booking records were excluded from the GitHub-ready package. The sanitized project has not been independently build-tested.
